## 0. 머신러닝 코드의 큰 흐름

책 2~4장의 모든 노트북은 결국 이 6단계입니다. 학생에게 이 지도를 먼저 보여주고, 지금 보는 코드가 몇 번 단계인지 항상 물어보세요.

```
① 데이터 불러오기     pd.read_csv(...)  /  load_iris()
        ↓
② 데이터 손질(전처리)  결측치 채우기, 문자 → 숫자, 필요 없는 열 삭제
        ↓
③ 피처/레이블 나누기   X = 문제(피처들),  y = 정답(레이블)
        ↓
④ 학습/테스트 나누기   X_train, X_test, y_train, y_test = train_test_split(X, y)
        ↓
⑤ 학습 → 예측          model.fit(X_train, y_train)  →  pred = model.predict(X_test)
        ↓
⑥ 평가                 accuracy_score(y_test, pred)
```

> 💡 **X 는 대문자, y 는 소문자인 이유**: 수학에서 행렬(2차원)은 대문자, 벡터(1차원)는 소문자로 쓰는 관례 때문입니다. `X` 는 여러 열을 가진 **표(2차원)**, `y` 는 정답 **한 줄(1차원)** 입니다. 문법적인 규칙은 아니고 약속입니다.

## 1. 세 개의 주인공: ndarray · Series · DataFrame

머신러닝 코드에서 거의 모든 변수는 이 셋 중 하나입니다. **지금 손에 든 게 셋 중 무엇인지** 알면 쓸 수 있는 메서드와 결과가 정해집니다.

```python
import numpy as np                     # 넘파이: 숫자 배열 계산 라이브러리
import pandas as pd                    # 판다스: 표(엑셀 같은) 데이터 라이브러리

arr = np.array([[1, 2, 3], [4, 5, 6]])                       # 넘파이 2차원 배열
s = pd.Series([22, 38, 26], name='Age')                      # 판다스 Series: 이름표 붙은 한 줄
df = pd.DataFrame({'Age': [22, 38, 26],                      # 판다스 DataFrame: 여러 줄로 된 표
                   'Fare': [7.25, 71.28, 7.92]})

print(type(arr))    # 무슨 타입인지 확인
print(type(s))
print(type(df))
print(arr.shape, s.shape, df.shape)   # 모양(행, 열) — 셋 다 shape 속성이 있다 (괄호 없음!)
```

실행 결과:
```
<class 'numpy.ndarray'>
<class 'pandas.core.series.Series'>
<class 'pandas.core.frame.DataFrame'>
(2, 3) (3,) (3, 2)
```

| | `ndarray` (넘파이) | `Series` (판다스) | `DataFrame` (판다스) |
|---|---|---|---|
| 비유 | 숫자만 있는 격자 | 엑셀의 **열 하나** | 엑셀 **시트 전체** |
| 차원 | 1차원, 2차원, ... | 항상 1차원 | 항상 2차원 |
| 이름표 | 없음 (번호만) | 행 이름(index) + 자기 이름(name) | 행 이름(index) + 열 이름(columns) |
| 만드는 법 | `np.array(리스트)` | `pd.Series(리스트)` | `pd.DataFrame(딕셔너리)` |
| 확인 | `type(x)` → `numpy.ndarray` | `pandas.core.series.Series` | `pandas.core.frame.DataFrame` |

💬 **설명 포인트**
- 사이킷런은 입력으로 셋 다 받지만, **출력(`predict` 결과, 스케일러 결과 등)은 거의 항상 `ndarray`** 입니다. 그래서 "판다스 표를 넣었는데 넘파이 배열이 나왔다" 는 일이 자주 생깁니다.
- 셋 사이를 오가는 법:

```python
print(df.values)                 # DataFrame → ndarray (이름표를 떼고 값만)
print(type(df.values))
print(df['Age'].tolist())        # Series → 파이썬 리스트
print(pd.DataFrame(arr, columns=['a', 'b', 'c']))   # ndarray → DataFrame (열 이름을 붙여서)
```

실행 결과:
```
[[22.    7.25]
 [38.   71.28]
 [26.    7.92]]
<class 'numpy.ndarray'>
[22, 38, 26]
   a  b  c
0  1  2  3
1  4  5  6
```

## 2. 학생들이 꼭 묻는 질문 20개

### Q1. 왜 `train_test_split` 결과를 4개로 받나요?

```python
from sklearn.datasets import load_iris                       # 붓꽃 데이터 불러오는 함수
from sklearn.model_selection import train_test_split         # 학습/테스트 나누는 함수

iris = load_iris()                    # 반환: Bunch (딕셔너리처럼 쓰는 묶음 객체)
X = iris.data                         # 피처 4개짜리 표 → ndarray (150, 4)
y = iris.target                       # 정답(품종 0/1/2) → ndarray (150,)

result = train_test_split(X, y, test_size=0.2, random_state=11)   # 일단 '하나'로 받아본다
print(type(result))                   # 무엇이 돌아왔나?
print(len(result))                    # 몇 개가 들어있나?
for item in result:                   # 하나씩 꺼내서 모양을 본다
    print(type(item).__name__, item.shape)
```

실행 결과:
```
<class 'list'>
4
ndarray (120, 4)
ndarray (30, 4)
ndarray (120,)
ndarray (30,)
```

💬 **설명 포인트**
- `train_test_split` 은 **4개짜리 리스트**를 돌려주도록 만들어진 함수입니다. 순서는 항상 `[X 학습용, X 테스트용, y 학습용, y 테스트용]`.
- 그래서 [언패킹](01_기초.md#5-2--언패킹--왜-두-개네-개로-받지의-정답)으로 한 번에 나눠 받습니다:

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=11)
print(X_train.shape, X_test.shape, y_train.shape, y_test.shape)   # 150개 중 20%(30개)가 테스트
```

실행 결과:
```
(120, 4) (30, 4) (120,) (30,)
```

- **X 를 2개 넣으면 4개, X 를 1개만 넣으면 2개**가 나옵니다. 넣은 배열마다 "학습용, 테스트용" 2개씩 돌려주기 때문입니다.

```python
a_train, a_test = train_test_split(X, test_size=0.2, random_state=11)   # 배열 1개 → 2개 반환
print(a_train.shape, a_test.shape)
```

실행 결과:
```
(120, 4) (30, 4)
```

> ⚠️ 순서를 바꿔 받으면(`X_train, y_train, X_test, y_test = ...`) **에러 없이** 엉뚱한 데이터가 들어갑니다. 나중에 `fit` 에서 "샘플 수가 안 맞는다" 는 에러가 나서야 알게 됩니다.

### Q2. `.sum()` 뒤에 왜 또 `.sum()` 이 오나요? (메서드 체이닝)

**규칙: 점은 왼쪽부터 하나씩 실행되고, 각 점의 결과(반환값)에 다음 점이 적용된다.**

```python
df = pd.DataFrame({'Age':   [22, None, 26, None],
                   'Cabin': [None, 'C85', None, 'C123'],
                   'Fare':  [7.25, 71.28, 7.92, 53.1]})

step1 = df.isna()          # 각 칸이 비었는지(NaN/None) True/False 로 → DataFrame (4행 3열)
step2 = step1.sum()        # 열마다 True 개수를 센다(True=1, False=0) → Series (3개)
step3 = step2.sum()        # Series 의 숫자를 모두 더한다 → 정수 하나

print(type(step1).__name__, step1.shape)
print(step1)
print(type(step2).__name__, step2.shape)
print(step2)
print(type(step3).__name__, step3)
print(df.isna().sum().sum())   # 위 세 줄을 한 줄로 = 같은 결과
```

실행 결과:
```
DataFrame (4, 3)
     Age  Cabin   Fare
0  False   True  False
1   True  False  False
2  False   True  False
3   True  False  False
Series (3,)
Age      2
Cabin    2
Fare     0
dtype: int64
int64 4
4
```

💬 **설명 포인트**
- `.sum()` 은 **한 차원을 줄입니다**: 표(2차원) → 열별 합계 한 줄(1차원) → 숫자 하나(0차원).
- 같은 이름의 `.sum()` 이지만 **앞의 것은 DataFrame 의 sum, 뒤의 것은 Series 의 sum** 입니다. 무엇에 붙었느냐에 따라 하는 일이 다릅니다.
- 체이닝이 헷갈리면 **한 단계씩 변수에 담아 `type()` 을 찍어보라**고 가르치세요. 위 코드처럼.

### Q4. `df['Age']` 와 `df[['Age']]` 는 뭐가 달라요?

```python
a = df['Age']             # 대괄호 안에 '문자열 하나' → 열 하나를 Series 로
b = df[['Age']]           # 대괄호 안에 '리스트' ['Age'] → 열 목록을 DataFrame 으로
c = df[['Age', 'Fare']]   # 리스트에 여러 개 → DataFrame

print(type(a).__name__, a.shape)
print(type(b).__name__, b.shape)
print(type(c).__name__, c.shape)
```

실행 결과:
```
Series (4,)
DataFrame (4, 1)
DataFrame (4, 2)
```

💬 **설명 포인트**
- 바깥 `[ ]` 는 "꺼내라", 안쪽 `[ ]` 는 "**리스트**". 즉 `df[['Age']]` = `df[ ['Age'] ]` = "열 이름 리스트로 꺼내라" → 결과는 항상 표(DataFrame).
- **언제 무엇을 쓰나?**
  - 정답(레이블) `y` 는 1차원이어야 하므로 → `df['Survived']` (Series)
  - 피처 `X` 는 2차원이어야 하므로 → `df[['Age', 'Fare']]` (DataFrame). **피처가 하나뿐이어도** `df[['Age']]` 로 꺼내야 합니다.

### Q5. `predict_proba(...)[:, 1]` 은 뭔가요?

```python
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression

cancer = load_breast_cancer()                                   # 유방암 데이터 (0: 악성, 1: 양성)
X_train, X_test, y_train, y_test = train_test_split(
    cancer.data, cancer.target, test_size=0.2, random_state=0)

lr = LogisticRegression(max_iter=5000)                          # 모델 객체 만들기
lr.fit(X_train, y_train)                                        # 학습

pred = lr.predict(X_test)                # 예측한 '클래스' → ndarray 1차원
proba = lr.predict_proba(X_test)         # 클래스별 '확률' → ndarray 2차원 (샘플 수, 클래스 수)

print(pred.shape)                        # (114,)
print(proba.shape)                       # (114, 2)
print(pred[:3])                          # 앞 3개 예측
print(proba[:3])                         # 앞 3개 확률: [0일 확률, 1일 확률]
print(proba[:3, 1])                      # [:, 1] → 모든 행의 1번 열 = '1일 확률'만 → 1차원
```

실행 결과:
```
(114,)
(114, 2)
[0 1 1]
[[0.99414703 0.00585297]
 [0.03083694 0.96916306]
 [0.00135296 0.99864704]]
[0.00585297 0.96916306 0.99864704]
```

💬 **설명 포인트**
- `proba` 는 **2차원 표**입니다. 각 행이 샘플 하나, 열 0 = 클래스 0일 확률, 열 1 = 클래스 1일 확률. 한 행의 합은 1.
- `[:, 1]` 읽는 법: `[행, 열]` → `[:` 모든 행`, 1]` 1번 열 → "모든 샘플의 '1일 확률'". 결과는 1차원.
- `roc_auc_score`, `precision_recall_curve` 같은 함수는 **"1일 확률"(1차원)** 을 원하므로 `[:, 1]` 을 붙여서 넘깁니다.
- `predict()` 는 사실 내부적으로 "1일 확률이 0.5 보다 크면 1" 로 결정합니다. 이 0.5 를 바꾸는 게 3장의 **임곗값(threshold) 조정**입니다.

### Q6. `reshape(-1, 1)` 은 왜 붙이나요?

```python
from sklearn.preprocessing import Binarizer

p1 = proba[:, 1]                      # 1차원 (114,)
print(p1.shape)

p2 = p1.reshape(-1, 1)                # 2차원 (114, 1) 로 바꿈. -1 = "개수는 알아서 계산"
print(p2.shape)

binarizer = Binarizer(threshold=0.5)  # 0.5 보다 크면 1, 아니면 0 으로 바꾸는 변환기
print(binarizer.fit_transform(p2)[:5].ravel())   # 2차원 입력 OK. 보기 좋게 ravel() 로 1차원으로 펴서 출력
```

실행 결과:
```

(114, 1)
[0. 1. 1. 1. 1.]
```

```python
# (에러 예시)
binarizer.fit_transform(p1)           # 1차원을 그대로 넣으면?
```

실행 결과:
```

```

💬 **설명 포인트**
- 사이킷런의 변환기(`Binarizer`, `StandardScaler`, `MinMaxScaler` 등)와 모델의 `fit(X)` 는 **X 가 반드시 2차원 (샘플 수, 피처 수)** 이어야 합니다. 피처가 하나뿐이어도 `(n, 1)` 모양이어야 합니다.
- `reshape(-1, 1)` = "열은 1개로, 행은 알아서" → 세로로 세운 한 줄.
- 반대로 `reshape(-1)` 또는 `ravel()` = "1차원으로 펴라".

| 코드 | 결과 모양 | 뜻 |
|---|---|---|
| `a.reshape(-1, 1)` | `(n, 1)` | 세로 한 줄 (2차원) |
| `a.reshape(1, -1)` | `(1, n)` | 가로 한 줄 (2차원) |
| `a.reshape(-1)` / `a.ravel()` | `(n,)` | 1차원 |

### Q9. 판다스 조건에서 왜 `and` 대신 `&` 를 쓰고 괄호를 치나요?

```python
df = pd.DataFrame({'Age': [22, 65, 70, 30], 'Pclass': [3, 1, 3, 1]})

cond1 = df['Age'] > 60                  # Series 와 숫자 비교 → '각 행마다' 비교한 True/False Series
print(cond1.tolist())
cond2 = df['Pclass'] == 1
print(cond2.tolist())
print((cond1 & cond2).tolist())         # & : 같은 위치끼리 '그리고' → True/False Series
print(df[cond1 & cond2])                # True 인 행만 남긴다 (불린 인덱싱)
```

실행 결과:
```

[False, True, False, True]
[False, True, False, False]
   Age  Pclass
1   65       1
```

```python
# (에러 예시)
df[(df['Age'] > 60) and (df['Pclass'] == 1)]    # and 를 쓰면?
```

실행 결과:
```
ValueError: The truth value of a Series is ambiguous. Use a.empty, a.bool(), a.item(), a.any() or a.all().
```

💬 **설명 포인트**
- `and` 는 **True/False 하나 대 하나**를 비교하는 파이썬 기본 문법입니다. 그런데 `df['Age'] > 60` 은 값이 4개짜리 Series 라서 "이게 전체적으로 True 냐?" 를 판단할 수 없어 에러가 납니다.
- `&`(그리고), `|`(또는), `~`(아니다)는 **같은 위치끼리 하나하나** 계산합니다.
- **괄호가 필요한 이유**: `&` 가 `>`, `==` 보다 먼저 계산되기 때문입니다. 괄호가 없으면 `df['Age'] > (60 & df['Pclass']) == 1` 처럼 엉뚱하게 묶입니다.

### Q10. `for train_index, test_index in kfold.split(X):` — 왜 변수가 두 개?

```python
splits = kfold.split(data)               # 반환: 제너레이터 (아직 계산 안 됨, for 로 하나씩 꺼내는 것)
print(type(splits).__name__)

first = next(iter(kfold.split(data)))    # 첫 번째 것만 꺼내본다
print(type(first).__name__, len(first))  # 튜플, 원소 2개 → 그래서 변수 2개로 받는다
print(first)

for i, (train_index, test_index) in enumerate(kfold.split(data)):   # 매번 (학습번호들, 검증번호들) 튜플
    print(i, '학습:', data[train_index], ' 검증:', data[test_index])   # 번호 배열로 데이터를 뽑는다(팬시 인덱싱)
```

실행 결과:

### Q13. `df['Age'].apply(lambda x: ...)` 는 어떻게 동작하나요?

```python
df['Age_cat'] = df['Age'].apply(get_category)                       # 함수 이름을 넘긴다 (괄호 없이!)

df['Child_Adult'] = df['Age'].apply(lambda x: 'Child' if x <= 15 else 'Adult')
```

```
Series
```

💬 **설명 포인트**

### Q16. `precision_recall_curve` 는 왜 3개를 돌려주고, 길이도 다른가요?

```python
from sklearn.metrics import precision_recall_curve

pred_proba_1 = lr.predict_proba(X_test)[:, 1]                       # 1일 확률 (1차원)
result = precision_recall_curve(y_test, pred_proba_1)
print(type(result).__name__, len(result))                           # 3개짜리 튜플

precisions, recalls, thresholds = precision_recall_curve(y_test, pred_proba_1)   # 3개로 언패킹

```

```
tuple 3
(115,) (115,) (114,)
```

💬 **설명 포인트**
- 이 함수는 "임곗값을 여러 개 바꿔가며 정밀도/재현율을 계산"하므로 **(정밀도 배열, 재현율 배열, 임곗값 배열)** 3개를 돌려줍니다. → 3개로 받는 이유.
- 정밀도·재현율 배열은 맨 끝에 (정밀도=1, 재현율=0) 이라는 점을 하나 더 붙여서 주기 때문에 **임곗값보다 1개 많습니다.** 그래서 책 3장에서 그래프를 그릴 때 `precisions[0:threshold_boundary]` 처럼 길이를 맞춥니다.

### Q17. `fit_transform()` 과 `transform()` 은 뭐가 달라요? 테스트에는 왜 fit 을 안 해요?

```python
from sklearn.preprocessing import StandardScaler

train = np.array([[1.0], [2.0], [3.0]])          # 학습 데이터 (평균 2)
test = np.array([[4.0]])                         # 테스트 데이터

scaler = StandardScaler()
train_scaled = scaler.fit_transform(train)       # fit(평균·표준편차 계산·저장) + transform(변환) 한 번에
print(scaler.mean_)                              # fit 으로 저장된 학습 데이터 평균 → [2.]
print(train_scaled.ravel())

print(scaler.transform(test).ravel())            # ✅ 학습 데이터 기준(평균 2)으로 변환
print(StandardScaler().fit_transform(test).ravel())   # ❌ 테스트로 다시 fit → 기준이 바뀌어 엉뚱한 값
print(type(train_scaled).__name__)               # 반환 타입: DataFrame 을 넣어도 ndarray 로 나온다
```

실행 결과:
```
[2.]
[-1.22474487  0.          1.22474487]
[2.44948974]
[0.]
ndarray
```

💬 **설명 포인트**
- `fit` = **기준을 배운다**(평균, 최솟값/최댓값, 문자→숫자 대응표 등). `transform` = **배운 기준대로 바꾼다**.
- 테스트 데이터는 "처음 보는 데이터" 라고 가정하므로, **학습 데이터로 배운 기준 그대로** 바꿔야 공정합니다.
- 규칙: **학습 데이터 → `fit_transform()`, 테스트 데이터 → `transform()`**.
- 변환 결과는 **`ndarray`** 라서 열 이름이 사라집니다. 필요하면 `pd.DataFrame(결과, columns=원래표.columns)`.

### 6-1. 사이킷런과 '호환되는' 나만의 분류기 (3장 MyDummyClassifier 확장)

책 3장은 `BaseEstimator` 를 상속해 "성별만 보고 생존을 맞히는 가짜 모델"을 만듭니다. 같은 방식으로, 이번엔 **진짜로 학습하는** 간단한 모델을 만들고 사이킷런 함수들(`cross_val_score`, `accuracy_score`)에 그대로 넣어 봅니다.

**모델 아이디어 — "가장 가까운 평균" 분류기**: 학습 때 클래스별 피처 평균을 계산해 두고, 예측 때는 평균이 가장 가까운 클래스로 분류합니다.

```python
from sklearn.base import BaseEstimator, ClassifierMixin

class NearestMeanClassifier(ClassifierMixin, BaseEstimator):    # 사이킷런 모델의 부모 클래스들을 상속 (Mixin 을 먼저 쓰는 게 규칙)
    def fit(self, X, y):
        X = np.asarray(X)                                       # DataFrame 이 와도 ndarray 로 통일
        y = np.asarray(y)
        self.classes_ = np.unique(y)                            # 정답 종류 → ndarray (예: [0 1 2])
        self.means_ = np.array([X[y == c].mean(axis=0)         # 클래스 c 인 행만 골라(불린 인덱싱) 열별 평균
                                for c in self.classes_])       # → 리스트 컴프리헨션 → ndarray (클래스 수, 피처 수)
        return self                                             # 사이킷런 약속: fit 은 self 를 돌려준다

    def predict(self, X):
        X = np.asarray(X)
        # 각 샘플과 각 클래스 평균 사이의 거리 → (샘플 수, 클래스 수)
        dists = np.array([np.sqrt(((X - m) ** 2).sum(axis=1)) for m in self.means_]).T
        nearest = dists.argmin(axis=1)                          # 행마다 거리가 가장 작은 '열 번호'
        return self.classes_[nearest]                           # 번호 → 실제 클래스 값 → ndarray (샘플 수,)
```

```python

    iris.data, iris.target, test_size=0.2, random_state=11)

print('score():', round(nm.score(X_test, y_test), 4))             # ClassifierMixin 이 score() 를 공짜로 줌
```

💬 **설명 포인트**
- `fit()` 이 `self` 를 돌려주고 `predict()` 가 `ndarray` 를 돌려주기만 하면, **사이킷런의 모든 도구가 내 모델을 사이킷런 모델처럼** 다룹니다. → "약속(반환 타입)을 지키는 게 왜 중요한가" 를 보여주는 예제.
- `self.classes_`, `self.means_` 처럼 **학습으로 생긴 값에 `_`** 를 붙인 것도 사이킷런 약속입니다(Q12).
- `X[y == c]` : `y == c` 는 True/False 배열 → 그걸로 X 의 행을 거름(불린 인덱싱) → "정답이 c 인 샘플들만".

### 6-2. 교차 검증을 직접 구현하기 (2.4장)

```python
def my_cross_val(model, X, y, n_splits=5):               # 반환: 점수 ndarray
    kfold = KFold(n_splits=n_splits, shuffle=True, random_state=0)
    scores = []                                          # 회차별 점수를 모을 빈 리스트
    for train_idx, test_idx in kfold.split(X):           # 매 회차 (학습 번호들, 검증 번호들) 튜플을 언패킹
        model.fit(X[train_idx], y[train_idx])            # 번호 배열로 데이터를 뽑아 학습
        pred = model.predict(X[test_idx])                # 검증 데이터로 예측
        scores.append(accuracy_score(y[test_idx], pred)) # float 점수를 리스트에 추가 (append 반환값은 None 이니 받지 않음!)
    return np.array(scores)                              # 리스트 → ndarray 로 바꿔서 돌려준다
```

### 6-3. 전 과정 한 번에 — 함수로 정리하기 (4장 스타일)

책 4장은 반복되는 코드를 함수로 묶습니다. 각 함수가 **무엇을 받아서 무엇을 돌려주는지** 표시해 둡니다.

```python
def get_dataset(test_size=0.2):
    """데이터를 불러와 나눈다. 반환: (X_train, X_test, y_train, y_test) 4개짜리 튜플"""
    data = load_breast_cancer()
    X = pd.DataFrame(data.data, columns=data.feature_names)   # 열 이름을 붙여 DataFrame 으로
    y = pd.Series(data.target, name='target')
    return train_test_split(X, y, test_size=test_size, random_state=0, stratify=y)

def get_model_eval(model, X_train, X_test, y_train, y_test):
    """학습 → 예측 → 평가. 반환: 점수 dict"""
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    proba = model.predict_proba(X_test)[:, 1]
    return {'model': model.__class__.__name__,
            'accuracy': round(accuracy_score(y_test, pred), 4),
            'f1': round(f1_score(y_test, pred), 4),
            'auc': round(roc_auc_score(y_test, proba), 4)}

X_train, X_test, y_train, y_test = get_dataset()           # 함수가 4개를 돌려주니 4개로 받는다
print(type(X_train).__name__, X_train.shape)

results = []                                               # dict 들을 모을 리스트
for model in [DecisionTreeClassifier(max_depth=4, random_state=0),
              RandomForestClassifier(n_estimators=100, random_state=0),
              LogisticRegression(max_iter=5000)]:
    results.append(get_model_eval(model, X_train, X_test, y_train, y_test))

print(pd.DataFrame(results))                               # dict 의 리스트 → DataFrame (행 = 모델)
```

실행 결과:

- `get_dataset()` 은 `train_test_split` 의 반환값을 **그대로 return** 합니다. 그래서 `get_dataset()` 도 4개짜리를 돌려주고, 부르는 쪽도 4개로 받습니다. **"함수가 무엇을 돌려주는지 따라가면, 왜 그렇게 받는지 보인다."**
- `pd.DataFrame(딕셔너리들의 리스트)` → 딕셔너리 하나가 한 행, 키가 열 이름이 됩니다. 결과 비교표를 만들 때 아주 유용합니다.

```python
def objective_func(search_space):                         # hyperopt 가 search_space 에서 값 하나씩 뽑아 넣어준다
    model = XGBClassifier(
        max_depth=int(search_space['max_depth']),         # ⚠️ 6.0 → 6 으로 int() 변환 필수
        learning_rate=search_space['learning_rate'])
    acc = cross_val_score(model, X_train, y_train, scoring='accuracy', cv=3)   # ndarray
    return {'loss': -1 * np.mean(acc), 'status': STATUS_OK}   # 반환: dict. 'loss' 를 '최소화'하므로 정확도에 -1 을 곱함

trials = Trials()                                         # 매 시도 기록을 담을 객체
best = fmin(fn=objective_func,                            # 함수 이름을 넘긴다 (괄호 없이! Q13 과 같은 원리)
            space=search_space, algo=tpe.suggest,
            max_evals=50, trials=trials)
print(best)                                               # 반환: dict  예) {'learning_rate': 0.13, 'max_depth': 6.0}
```

| 코드 | 반환 | 주의 |
|---|---|---|
| `hp.quniform(...)` 이 뽑은 값 | **`float`** | 정수 파라미터에는 `int()` |
| `objective_func(...)` | `dict` | `'loss'` 키 필수, 작을수록 좋음 |
| `fmin(...)` | `dict` | 최적값도 `max_depth: 6.0` 처럼 float |
| `trials.results` | `list` of `dict` | 매 시도의 loss |
| `trials.vals` | `dict` of `list` | 매 시도의 파라미터 값 |

💬 **설명 포인트**: `fn=objective_func` 처럼 **함수 이름만 넘기는** 이유: "이 함수를 hyperopt 가 50번 알아서 불러라" 는 뜻이기 때문입니다. 괄호를 붙이면(`objective_func()`) 지금 한 번 실행한 결과(dict)를 넘기게 되어 에러가 납니다.

## 9. 반환 타입 치트시트

### 9-1. "None 을 돌려주는" 함정 (변수에 담지 말 것)

| 코드 | 올바른 사용 |
|---|---|

|---|---|
