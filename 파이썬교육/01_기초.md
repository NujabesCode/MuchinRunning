## 1. 자료형

### 1-1. 변수 — 값에 이름표 붙이기

```python
age = 22               # 22 라는 값에 age 라는 이름표를 붙인다 (= 는 '같다'가 아니라 '저장한다')
name = 'Braund'        # 문자열 'Braund' 를 name 에 저장
print(age)             # age 에 저장된 값 22 를 출력
print(name)            # name 에 저장된 값 Braund 를 출력

age = 23               # 같은 이름에 새 값을 저장하면 이전 값(22)은 사라진다
print(age)             # 23
```

실행 결과:
```
22
Braund
23
```

💬 **설명 포인트**
- `=` 는 수학의 "같다"가 아닙니다. **오른쪽 값을 계산해서 왼쪽 이름에 저장**하라는 명령입니다.
- 그래서 `x = x + 1` 같은 코드가 가능합니다. "x 의 현재 값에 1 을 더해서 다시 x 에 저장"이라는 뜻입니다.
- 변수 이름 규칙: 영문/숫자/밑줄(`_`) 사용, 숫자로 시작 불가, 대소문자 구분(`Age` 와 `age` 는 다른 변수).

### 1-4. 형 변환 — 자료형 바꾸기

```python
x = '5'                # 따옴표로 감쌌으므로 문자열 '5'
y = int(x)             # int() : 문자열 '5' 를 정수 5 로 바꿔서 돌려준다
print(y + 1)           # 정수끼리 더하기 → 6

z = float('2.5')       # float() : 문자열 → 실수 2.5
print(z)

w = str(100)           # str() : 정수 100 → 문자열 '100'
print(w + '점')        # 문자열끼리 이어 붙이기 → '100점'

print(int(3.9))        # 실수 → 정수 : 소수점 아래를 '버린다' (반올림 아님!) → 3
print(round(3.9))      # 반올림하려면 round() 사용 → 4
print(round(0.83456, 2))  # 소수 둘째 자리까지 반올림 → 0.83
```

실행 결과:
```
6
2.5
100점
3
4
0.83
```

| 함수 | 하는 일 | 돌려주는 것(반환 타입) |
|---|---|---|
| `int(x)` | 정수로 변환 (소수점 버림) | `int` |
| `float(x)` | 실수로 변환 | `float` |
| `str(x)` | 문자열로 변환 | `str` |
| `bool(x)` | 참/거짓으로 변환 (`0`, `''`, `None` → `False`) | `bool` |
| `round(x, n)` | 소수점 n 자리로 반올림 | `float` (n 생략 시 `int`) |

## 2. 연산자

### 2-1. 산술 연산자

```python
print(7 + 2)    # 더하기 → 9
print(7 - 2)    # 빼기 → 5
print(7 * 2)    # 곱하기 → 14
print(7 / 2)    # 나누기 → 3.5   (결과는 항상 float)
print(7 // 2)   # 몫 → 3         (소수점 아래 버림)
print(7 % 2)    # 나머지 → 1     (짝수/홀수 판별에 자주 씀)
print(7 ** 2)   # 거듭제곱 → 49  (7의 2제곱)
print(6 / 2)    # 나누어떨어져도 / 의 결과는 float → 3.0
```

실행 결과:
```
9
5
14
3.5
3
1
49
3.0
```

💬 **설명 포인트**
- `/` 는 **항상 float** 를 돌려줍니다. `6 / 2` 도 `3` 이 아니라 `3.0`.
- `x ** 2` (제곱)은 책의 `lambda x: x ** 2` 에 나옵니다.

### 2-2. 비교 연산자 — 결과는 항상 bool

```python
a = 10
print(a > 5)     # 크다 → True
print(a < 5)     # 작다 → False
print(a >= 10)   # 크거나 같다 → True
print(a <= 9)    # 작거나 같다 → False
print(a == 10)   # 같다 → True    (= 1개는 저장, == 2개는 비교!)
print(a != 10)   # 다르다 → False
```

실행 결과:
```
True
False
True
False
True
False
```

💬 **설명 포인트**
- **`=` 와 `==` 를 구분**시키는 게 가장 중요합니다. `=` 는 저장, `==` 는 "같은지 물어보기".
- 비교의 결과는 언제나 `True` 또는 `False`(bool)입니다. 이 결과를 `if` 에 넣어 분기합니다.

```
True
False
```

### 3-2. 인덱싱 — 한 글자 꺼내기

```python
s = 'Python'
#    P  y  t  h  o  n
#    0  1  2  3  4  5     ← 앞에서부터 번호 (0부터 시작!)

```

### 3-3. 슬라이싱 — 구간 잘라내기

```python
s = 'Python'
print(s[0:2])    # 0번부터 2번 '전'까지 → 'Py'   (끝 번호는 포함하지 않음!)
print(s[:2])     # 시작 생략 = 처음부터 → 'Py'
print(s[2:])     # 끝 생략 = 끝까지 → 'thon'
print(s[:-1])    # 마지막 한 글자 빼고 전부 → 'Pytho'
print(s[::-1])   # 세 번째 값은 간격. -1 이면 거꾸로 → 'nohtyP'
print(s[:1])     # 첫 글자만 (결과는 문자열) → 'P'
```

실행 결과:
```
Py
Py
thon
Pytho
nohtyP
P
```

💬 **설명 포인트**
- 형식: `[시작:끝:간격]`. **끝 번호는 포함하지 않습니다.** "0번부터 2번 *앞*까지"라고 읽으세요.
- `[:-1]` (마지막 빼고 전부) 와 `[-1]` (마지막 하나)는 **심화에서 피처/레이블을 나눌 때** 그대로 쓰입니다: `X = df.iloc[:, :-1]`, `y = df.iloc[:, -1]`.
- `[::-1]` (뒤집기)는 정렬 결과를 **내림차순**으로 바꿀 때 씁니다.
- 책 1장의 `titanic_df['Cabin'].str[:1]` 은 "Cabin 값의 첫 글자만" 이라는 뜻입니다.

### 3-4. 문자열 메서드

```python
s = '  Hello, World  '
print(s.strip())             # 양쪽 공백 제거 → 'Hello, World'
print(s.lower())             # 소문자로 → '  hello, world  '
print(s.upper())             # 대문자로 → '  HELLO, WORLD  '
print(s.replace('World', 'Python'))  # 바꾸기 → '  Hello, Python  '

csv_line = 'Braund,male,22'
parts = csv_line.split(',')  # ',' 를 기준으로 쪼개서 '리스트'로 돌려준다
print(parts)                 # → ['Braund', 'male', '22']
print(type(parts))           # 반환 타입 확인 → list

words = ['Pclass', '1']
print('_'.join(words))       # 리스트를 '_' 로 이어 붙여 '문자열'로 → 'Pclass_1'
```

실행 결과:
```
Hello, World
  hello, world  
  HELLO, WORLD  
  Hello, Python  
['Braund', 'male', '22']
<class 'list'>
Pclass_1
```

| 메서드 | 하는 일 | 반환 타입 | 원본 변경? |
|---|---|---|---|
| `s.strip()` | 양쪽 공백 제거 | `str` | ❌ |
| `s.lower()` / `s.upper()` | 소/대문자 | `str` | ❌ |
| `s.replace(a, b)` | a 를 b 로 바꿈 | `str` | ❌ |
| `s.split(구분자)` | 쪼개기 | **`list`** | ❌ |
| `구분자.join(리스트)` | 이어 붙이기 | `str` | ❌ |
| `s.startswith(x)` | x 로 시작? | `bool` | ❌ |

💬 **설명 포인트**
- **문자열은 절대 바뀌지 않습니다(불변).** `s.lower()` 를 해도 `s` 자체는 그대로입니다. 바뀐 결과를 쓰려면 `s = s.lower()` 처럼 **다시 저장**해야 합니다.

```python
s = 'ABC'
s.lower()       # 결과 'abc' 를 만들었지만 아무 데도 저장 안 함 → 버려짐
print(s)        # 그대로 'ABC'
s = s.lower()   # 결과를 s 에 다시 저장
print(s)        # 'abc'
```

실행 결과:
```
ABC
abc
```

### 3-5. 문자열 포맷팅 — 숫자를 글자 속에 넣기

책 전체에서 결과를 출력할 때 가장 많이 쓰는 문법입니다.

```python
acc = 0.836312          # 정확도
prec = 0.75             # 정밀도

# 방법 1: .format()  ← 책에서 주로 사용
print('정확도: {0:.4f}'.format(acc))
#        {0}   : format() 괄호 안의 0번째 값이 들어갈 자리
#        :.4f  : 소수점 아래 4자리까지 실수(float)로 표시

print('정확도: {0:.4f}, 정밀도: {1:.4f}'.format(acc, prec))
#        {0} 자리에 acc, {1} 자리에 prec 가 들어간다

# 방법 2: f-string  ← 요즘 더 많이 쓰는 방식 (따옴표 앞에 f)
print(f'정확도: {acc:.4f}')          # 중괄호 안에 변수 이름을 바로 쓴다

# 방법 3: print 에 콤마로 여러 개 넘기기 (자동으로 한 칸 띄움)
print('정확도:', acc)
```

실행 결과:
```
정확도: 0.8363
정확도: 0.8363, 정밀도: 0.7500
정확도: 0.8363
정확도: 0.836312
```

| 서식 | 의미 | 예: 값이 `0.836312` 일 때 |
|---|---|---|
| `{0}` | 그대로 | `0.836312` |
| `{0:.2f}` | 소수 2자리 | `0.84` |
| `{0:.4f}` | 소수 4자리 | `0.8363` |
| `{0:.1%}` | 퍼센트 | `83.6%` |
| `{0:,}` (정수) | 천 단위 콤마 | `1234567` → `1,234,567` |

## 4. 리스트

### 4-1. 리스트 만들기와 꺼내기

```python
scores = [80, 95, 70, 88]    # 대괄호 [ ] 안에 콤마로 구분해서 여러 값을 묶는다
print(scores)                # 리스트 전체 출력
print(scores[0])             # 0번째 값 → 80
print(scores[-1])            # 마지막 값 → 88
print(scores[1:3])           # 1번~2번 (3번 앞까지) → [95, 70]  ← 슬라이싱 결과도 리스트
print(len(scores))           # 원소 개수 → 4

mixed = [1, 'a', 3.5, True]  # 여러 자료형을 섞어 담을 수도 있다
nested = [[1, 2], [3, 4]]    # 리스트 안에 리스트 (2차원)
print(nested[1])             # 1번째 원소 = [3, 4]
print(nested[1][0])          # 1번째 원소의 0번째 = 3
```

실행 결과:
```
[80, 95, 70, 88]
80
88
[95, 70]
4
[3, 4]
3
```

💬 **설명 포인트**
- 인덱싱/슬라이싱 규칙은 **문자열과 똑같습니다.**
- `nested[1][0]` 은 **왼쪽부터 차례로** 꺼냅니다: `nested[1]` → `[3, 4]` → 그것의 `[0]` → `3`. 이 "왼쪽부터 차례로 처리"가 심화의 **메서드 체이닝**(`df.isna().sum().sum()`)을 이해하는 열쇠입니다.

### 4-2. 리스트 수정 — 리스트는 바뀐다(가변)

```python
cols = ['Name', 'Sex']
cols.append('Age')           # 맨 뒤에 추가. 리스트 '자체'가 바뀐다
print(cols)                  # → ['Name', 'Sex', 'Age']

cols.insert(0, 'Id')         # 0번 위치에 끼워 넣기
print(cols)                  # → ['Id', 'Name', 'Sex', 'Age']

cols.remove('Sex')           # 값으로 삭제
print(cols)                  # → ['Id', 'Name', 'Age']

cols[0] = 'PassengerId'      # 0번 값을 바꾸기
print(cols)                  # → ['PassengerId', 'Name', 'Age']

last = cols.pop()            # 마지막 값을 '꺼내서' 돌려주고 리스트에서는 삭제
print(last)                  # → 'Age'
print(cols)                  # → ['PassengerId', 'Name']
```

실행 결과:
```
['Name', 'Sex', 'Age']
['Id', 'Name', 'Sex', 'Age']
['Id', 'Name', 'Age']
['PassengerId', 'Name', 'Age']
Age
['PassengerId', 'Name']
```

### 4-3. ⚠️ 가장 중요한 함정: append 의 반환값은 None

```python
cols = ['Name', 'Sex']
result = cols.append('Age')  # append 는 리스트를 '제자리에서' 바꾸고, 아무것도 돌려주지 않는다
print(result)                # → None
print(cols)                  # 리스트 자체는 바뀌었다 → ['Name', 'Sex', 'Age']
```

실행 결과:
```
None
['Name', 'Sex', 'Age']
```

💬 **설명 포인트 — 반드시 짚고 넘어가세요**

파이썬 함수/메서드는 두 종류가 있습니다.

| 종류 | 예 | 하는 일 | 돌려주는 것 |
|---|---|---|---|
| **새 결과를 만들어 돌려주는 것** | `sorted(lst)`, `s.lower()`, `np.sort(arr)` | 원본은 그대로 두고 새 값을 만듦 | 새 값 |
| **원본을 직접 바꾸는 것(제자리 수정)** | `lst.append(x)`, `lst.sort()`, `df.drop(..., inplace=True)` | 원본을 고침 | **`None`** |

> 원본을 직접 바꾸는 함수는 "결과는 원본에 이미 반영했으니 따로 줄 게 없다"는 의미로 `None` 을 돌려줍니다.
> 그래서 `cols = cols.append('Age')` 처럼 쓰면 `cols` 가 `None` 이 되어버립니다.

### 4-4. 정렬 — sorted() vs .sort()

```python
nums = [3, 1, 2]

new_list = sorted(nums)      # sorted() : 정렬된 '새 리스트'를 돌려준다. 원본은 그대로
print(new_list)              # → [1, 2, 3]
print(nums)                  # 원본 → [3, 1, 2]

r = nums.sort()              # .sort() : 원본을 직접 정렬. 반환값 None
print(r)                     # → None
print(nums)                  # 원본이 바뀌었다 → [1, 2, 3]

print(sorted(nums, reverse=True))   # 내림차순 → [3, 2, 1]
```

실행 결과:
```
[1, 2, 3]
[3, 1, 2]
None
[1, 2, 3]
[3, 2, 1]
```

💬 **설명 포인트**: 넘파이에서도 똑같습니다. `np.sort(arr)` 는 새 배열을 돌려주고, `arr.sort()` 는 `None` 을 돌려줍니다. (책 1.3장)

## 5. 튜플 · 딕셔너리 · 집합

### 5-1. 튜플 — 바꿀 수 없는 리스트

```python
point = (3, 5)           # 소괄호 ( ) 로 만든다
print(point[0])          # 꺼내는 방법은 리스트와 같다 → 3
print(len(point))        # → 2
# point[0] = 10          # ← 에러! 튜플은 값을 바꿀 수 없다

single = (5,)            # 원소가 1개인 튜플은 반드시 콤마를 붙인다
print(type(single))      # → tuple
print(type((5)))         # 콤마가 없으면 그냥 괄호 친 숫자 5 → int
```

실행 결과:
```
3
2
<class 'tuple'>
<class 'int'>
```

💬 **설명 포인트**
- 머신러닝에서 튜플은 **데이터의 모양(shape)** 으로 가장 자주 만납니다. `df.shape` 의 결과가 `(891, 12)` 같은 튜플입니다. → "891행 12열".
- 1차원 배열의 shape 이 `(10,)` 처럼 **콤마가 붙어** 나오는 이유가 "원소 1개짜리 튜플"이기 때문입니다.

### 5-2. ⭐ 언패킹 — "왜 두 개(네 개)로 받지?"의 정답

```python
point = (3, 5)
x, y = point             # 튜플의 값을 순서대로 x, y 에 나눠 담는다 (언패킹)
print(x)                 # → 3
print(y)                 # → 5

rows, cols = (891, 12)   # df.shape 를 이렇게 받는 것과 같다
print(rows, '행', cols, '열')

a, b, c, d = [1, 2, 3, 4]   # 리스트도 언패킹 된다
print(a, d)                 # → 1 4

a, b = 1, 2              # 오른쪽 '1, 2' 는 괄호 없는 튜플 (1, 2)
a, b = b, a              # 값 바꾸기(swap)도 한 줄로
print(a, b)              # → 2 1
```

실행 결과:
```
3
5
891 행 12 열
1 4
2 1
```

💬 **설명 포인트 — 심화의 핵심 복선**
- 왼쪽 변수 개수와 오른쪽 원소 개수가 **반드시 같아야** 합니다. 다르면 `ValueError: too many values to unpack` 에러.
- 책의 `X_train, X_test, y_train, y_test = train_test_split(X, y)` 는 함수가 **4개짜리 묶음**을 돌려주기 때문에 4개로 받는 것입니다. 함수 하나가 여러 값을 돌려주는 원리는 [8-4](#8-4--값을-여러-개-돌려주기--왜-여러-변수로-받지) 에서 직접 만들어 봅니다.

```python
x, y = (1, 2, 3)         # 3개를 2개로 받으려고 하면?
```

실행 결과:
```
ValueError: too many values to unpack (expected 2)
```

## 6. 제어문 (if · for · while)

### 6-1. if / elif / else

```python
age = 30

if age <= 12:                 # 조건이 True 이면 아래 '들여쓴' 줄을 실행
    cat = 'Child'
elif age <= 18:               # 위 조건이 False 이고 이 조건이 True 이면
    cat = 'Teenager'
elif age <= 60:
    cat = 'Adult'
else:                         # 위 조건이 모두 False 이면
    cat = 'Elderly'

print(cat)                    # → 'Adult'
```

실행 결과:
```
Adult
```

## 7. 리스트 컴프리헨션

for 문으로 리스트를 만드는 것을 **한 줄**로 줄인 문법입니다.

```python
pred_probs = [0.2, 0.7, 0.55, 0.4]

# ① 일반 for 문
pred = []
for x in pred_probs:
    pred.append(1 if x > 0.5 else 0)
print(pred)

# ② 리스트 컴프리헨션 (①과 완전히 같은 결과)
pred = [1 if x > 0.5 else 0 for x in pred_probs]
#       ─────────────────── ──────────────────
#        각 x 를 이렇게 바꿔서    pred_probs 의 x 하나하나에 대해
print(pred)

# 조건으로 거르기 (if 가 뒤에 오면 '필터')
big = [x for x in pred_probs if x > 0.5]
print(big)

squares = [i ** 2 for i in range(5)]
print(squares)
```

실행 결과:
```
[0, 1, 1, 0]
[0, 1, 1, 0]
[0.7, 0.55]
[0, 1, 4, 9, 16]
```

💬 **설명 포인트**
- 읽는 법: **"`for` 뒤부터 읽고, 그다음 맨 앞을 읽는다."** → "pred_probs 의 각 x 에 대해, x > 0.5 면 1 아니면 0 을 담은 리스트".
- `if` 위치가 두 군데라 헷갈립니다:
  - **앞쪽** `A if 조건 else B for x in ...` → 값을 **바꾸기** (else 필수)
  - **뒤쪽** `x for x in ... if 조건` → 원소를 **거르기** (else 없음)

## 8. 함수

### 8-1. 함수 정의와 호출

```python
def add(a, b):          # def 함수이름(매개변수들):  ← 함수 '정의' (만들기만 함, 실행 안 됨)
    result = a + b      # 함수 안에서 할 일 (들여쓰기)
    return result       # return : 결과를 함수 밖으로 '돌려준다'

total = add(3, 5)       # 함수 '호출': a=3, b=5 로 실행 → return 된 값 8 이 total 에 저장
print(total)            # → 8
print(add(10, 20))      # 돌려받은 값을 바로 print 에 넘길 수도 있다 → 30
```

실행 결과:
```
8
30
```

💬 **설명 포인트 — 용어 정리**

| 용어 | 뜻 | 위 예에서 |
|---|---|---|
| **정의(define)** | 함수를 만드는 것. `def` 로 시작 | `def add(a, b):` |
| **호출(call)** | 만든 함수를 실행하는 것. `이름(...)` | `add(3, 5)` |
| **매개변수(parameter)** | 함수가 받을 재료의 이름 | `a`, `b` |
| **인자(argument)** | 호출할 때 실제로 넣는 값 | `3`, `5` |
| **반환값(return value)** | 함수가 돌려주는 결과 | `8` |

- **`return` 은 "함수 호출 자리를 그 값으로 바꿔치기한다"** 고 설명하면 이해가 빠릅니다. `total = add(3, 5)` → 실행 후 `total = 8` 이 됩니다.

### 8-2. print 와 return 의 차이 — 가장 많이 헷갈리는 부분

```python
def add_print(a, b):
    print(a + b)        # 화면에 '보여주기만' 한다

def add_return(a, b):
    return a + b        # 값을 '돌려준다' (화면에는 아무것도 안 나옴)

x = add_print(1, 2)     # 실행되면서 화면에 3 이 찍힘
y = add_return(1, 2)    # 화면에는 아무것도 안 나오지만 y 에 3 이 저장됨

print('x =', x)         # x 에는 무엇이? → None
print('y =', y)         # → 3
```

실행 결과:
```

x = None
y = 3
```

💬 **설명 포인트**
- **print 는 사람에게 보여주는 것, return 은 프로그램에게 넘겨주는 것.**
- 화면에 3 이 나왔다고 해서 그 값을 쓸 수 있는 게 아닙니다. `add_print` 가 돌려준 것은 `None` 입니다.
- 책 3장의 `get_clf_eval(y_test, pred)` 함수는 지표들을 **print 만** 하고 return 하지 않습니다. 그래서 `result = get_clf_eval(...)` 처럼 받아도 `result` 는 `None` 입니다.

이제 사이킷런의 `train_test_split` 과 **같은 모양의 함수**를 직접 만들어 봅니다.

```python
def my_split(data, labels, test_ratio=0.25):
    n_test = int(len(data) * test_ratio)      # 테스트로 쓸 개수 (25% → 정수로)
    X_train = data[n_test:]                    # 앞 n_test 개를 뺀 나머지 = 학습용 데이터
    X_test = data[:n_test]                     # 앞 n_test 개 = 테스트용 데이터
    y_train = labels[n_test:]                  # 정답도 같은 방식으로 나눈다
    y_test = labels[:n_test]
    return X_train, X_test, y_train, y_test    # 4개를 '이 순서대로' 돌려준다

data   = [10, 20, 30, 40, 50, 60, 70, 80]
labels = [0, 1, 0, 1, 0, 1, 0, 1]

X_train, X_test, y_train, y_test = my_split(data, labels)   # 4개로 받는다
print('X_train:', X_train)
print('X_test :', X_test)
print('y_train:', y_train)
print('y_test :', y_test)
```

실행 결과:
```
X_train: [30, 40, 50, 60, 70, 80]
X_test : [10, 20]
y_train: [0, 1, 0, 1, 0, 1]
y_test : [0, 1]
```

💬 **설명 포인트 — 학생에게 이렇게 설명하세요**
- "`train_test_split` 이 **4개를 돌려주도록 만들어져 있어서** 4개로 받는 겁니다. 순서도 함수를 만든 사람이 정한 것(`X_train, X_test, y_train, y_test`)이라 **문서에 적힌 순서대로** 받아야 합니다."
- 순서를 바꿔 받으면 에러는 안 나지만 **엉뚱한 데이터가 엉뚱한 변수에** 들어갑니다. (가장 무서운 버그)
- 함수가 몇 개를 돌려주는지 모르겠으면? → 하나로 받아서 `type()`, `len()` 을 찍어보면 됩니다.

### 8-6. 함수 안에서 다른 함수 호출하기

```python
def accuracy(y_true, y_pred):                       # 정답률을 '돌려주는' 함수
    correct = 0
    for t, p in zip(y_true, y_pred):                 # 정답과 예측을 짝지어 하나씩
        if t == p:
            correct += 1
    return correct / len(y_true)

def report(y_true, y_pred):                          # 결과를 '출력하는' 함수
    acc = accuracy(y_true, y_pred)                   # 함수 안에서 다른 함수를 부르고 반환값을 받는다
    print('정확도: {0:.4f}'.format(acc))

report([1, 0, 1, 1], [1, 0, 0, 1])
```

실행 결과:
```
정확도: 0.7500
```

```python
    for line in f:                                      # 한 줄씩 반복
        name, age = line.strip().split(',')             # 줄바꿈 제거 → 콤마로 쪼개기 → 언패킹
        print(name, '/', age)
```

## 13. 클래스

### 13-1. 클래스 = 설계도, 객체 = 설계도로 만든 물건

```python
class Dog:                               # Dog 라는 설계도(클래스) 정의
    def __init__(self, name, age):       # __init__ : 객체를 만들 때 자동으로 실행되는 '초기 설정' 메서드
        self.name = name                 # self.name : 이 객체'의' name 속성에 저장
        self.age = age                   # self.age  : 이 객체'의' age 속성에 저장

    def bark(self):                      # 메서드 : 클래스 안에 정의한 함수 (첫 매개변수는 항상 self)
        return self.name + ': 멍멍!'     # 자기 자신의 name 을 사용

    def get_older(self, years=1):        # 기본값이 있는 매개변수도 가능
        self.age += years                # 자기 속성을 바꾼다 (반환값 없음 → None)

d1 = Dog('바둑이', 3)        # 설계도로 객체(인스턴스) 생성 → __init__(self=d1, name='바둑이', age=3) 실행
d2 = Dog('흰둥이', 5)        # 같은 설계도로 다른 객체

print(d1.name)              # 속성 읽기 (괄호 없음) → 바둑이
print(d2.age)               # → 5
print(d1.bark())            # 메서드 호출 (괄호 있음) → 바둑이: 멍멍!
d1.get_older()              # d1 의 나이만 1 증가
print(d1.age, d2.age)       # → 4 5
print(type(d1))             # d1 의 자료형은 Dog
```

실행 결과:
```
바둑이
5
바둑이: 멍멍!
4 5
<class '__main__.Dog'>
```

💬 **설명 포인트**

| 용어 | 뜻 | 예 |
|---|---|---|
| **클래스** | 설계도 | `Dog`, `DecisionTreeClassifier` |
| **객체(인스턴스)** | 설계도로 찍어낸 실물 | `d1`, `dt_clf` |
| **속성(attribute)** | 객체가 가진 값. **괄호 없음** | `d1.name`, `df.shape` |
| **메서드(method)** | 객체가 할 수 있는 동작(함수). **괄호 있음** | `d1.bark()`, `model.fit()` |
| **`self`** | "나 자신(지금 이 객체)" | `self.name` = 이 객체의 이름 |
| **`__init__`** | 객체 만들 때 자동 실행 | `Dog('바둑이', 3)` 할 때 |

- `self` 설명 요령: "`d1.bark()` 라고 부르면 파이썬이 몰래 `Dog.bark(d1)` 로 바꿔서 실행합니다. 그래서 `self` 자리에 `d1` 이 들어갑니다."
- 클래스 이름은 관례상 **대문자로 시작**(`DecisionTreeClassifier`), 함수/변수는 소문자(`accuracy_score`). 이름만 봐도 **클래스인지 함수인지** 구분할 수 있습니다.

### 13-2. 클래스로 "아주 간단한 머신러닝 모델" 만들기

사이킷런 모델은 전부 **`fit()` 으로 배우고, `predict()` 로 예측하는 클래스**입니다. 똑같은 모양으로 직접 만들어 봅니다.

**문제**: 키(cm)를 보고 성인(1)인지 아닌지(0) 맞히기.
**아이디어**: 학습 데이터에서 "성인 평균 키"와 "아이 평균 키"의 **중간값**을 기준선으로 삼는다.

```python
class ThresholdClassifier:
    def __init__(self):
        self.threshold_ = None                 # 아직 학습 전이라 기준선이 없다. 학습으로 생기는 값은 이름 끝에 _ (사이킷런 관례)

    def fit(self, X, y):                       # X: 키 목록, y: 정답 목록(0/1)
        adults = [x for x, label in zip(X, y) if label == 1]     # 정답이 1(성인)인 키만
        kids = [x for x, label in zip(X, y) if label == 0]       # 정답이 0(아이)인 키만
        adult_mean = sum(adults) / len(adults)                   # 성인 평균 키
        kid_mean = sum(kids) / len(kids)                         # 아이 평균 키
        self.threshold_ = (adult_mean + kid_mean) / 2            # 두 평균의 중간 = 기준선 (객체에 저장!)
        return self                            # 사이킷런 관례: fit 은 자기 자신을 돌려준다

    def predict(self, X):
        return [1 if x >= self.threshold_ else 0 for x in X]     # 기준선 이상이면 1 → 예측 리스트를 돌려준다


X_train = [120, 130, 165, 170, 110, 180]       # 학습용 키
y_train = [0, 0, 1, 1, 0, 1]                   # 학습용 정답

model = ThresholdClassifier()                  # 1) 객체 생성 (반환: ThresholdClassifier 객체)
print('학습 전 기준선:', model.threshold_)       # → None

r = model.fit(X_train, y_train)                # 2) 학습 (반환: model 자기 자신)
print('학습 후 기준선:', model.threshold_)       # → 145.83...
print(r is model)                              # fit 이 돌려준 것이 model 자신인지 → True

pred = model.predict([125, 150, 175])          # 3) 예측 (반환: list)
print('예측:', pred)                            # → [0, 1, 1]
print(type(pred))
```

실행 결과:
```
학습 전 기준선: None
학습 후 기준선: 145.83333333333331
True
예측: [0, 1, 1]
<class 'list'>
```

💬 **설명 포인트 — 이 예제 하나로 사이킷런 전체가 이해됩니다**
- `fit()` 은 **데이터로 무언가(여기선 기준선)를 계산해서 객체 안(`self.threshold_`)에 저장**합니다. 그래서 학습 후에 `model.threshold_` 로 꺼내 볼 수 있습니다.
  → 사이킷런의 `model.feature_importances_`, `grid.best_params_` 같은 **끝에 `_` 붙은 속성**이 전부 "fit 하면서 계산해 저장한 값" 입니다.
- `fit()` 이 `self` 를 돌려주는 이유: `model.fit(X, y).predict(X2)` 처럼 **이어서 쓸 수 있게** 하려는 사이킷런의 약속입니다. 그래서 책에서는 `fit()` 의 반환값을 따로 받지 않고 그냥 `model.fit(X_train, y_train)` 만 씁니다.
- `predict()` 는 **예측 결과를 돌려줍니다.** 사이킷런에서는 리스트가 아니라 넘파이 배열(`ndarray`)로 돌려준다는 점만 다릅니다(심화).

### 14-2. 괄호가 있으면 메서드(동작), 없으면 속성(값)

```python
class Box:
    def __init__(self, w, h):
        self.width = w                   # 속성
        self.height = h                  # 속성
    def area(self):                      # 메서드
        return self.width * self.height

b = Box(3, 4)
print(b.width)        # 속성: 저장된 값을 '읽기만' 한다 → 3
print(b.area())       # 메서드: '실행'해서 결과를 돌려받는다 → 12
print(b.area)         # 괄호를 빼먹으면? → 실행되지 않고 '메서드 그 자체'가 출력된다
```

실행 결과:
```
3
12
<bound method Box.area of <__main__.Box object at 0x...>>
```

💬 **설명 포인트**
- 괄호를 **빼먹으면** 에러 대신 `<bound method ...>` 같은 이상한 글자가 나옵니다. 이걸 보면 "아, 괄호 빼먹었구나" 하면 됩니다.
- 반대로 속성에 괄호를 붙이면 에러: `df.shape()` → `TypeError: 'tuple' object is not callable` ("튜플은 호출할 수 없다" = shape 은 튜플 값이지 함수가 아니다).

| 심화에서 만날 예 | 종류 | 괄호 |
|---|---|---|
| `df.shape`, `df.columns`, `arr.ndim`, `model.feature_importances_` | 속성 | ❌ |
| `df.head()`, `df.sum()`, `model.fit(X, y)`, `arr.reshape(-1, 1)` | 메서드 | ✅ |

### 14-3. ⭐ 메서드 체이닝 — "`.sum()` 뒤에 왜 또 `.sum()` 이 오지?"

**핵심 규칙: 점은 왼쪽부터 하나씩 처리한다. 각 단계의 '결과(반환값)'에 다음 점을 적용한다.**

```python
text = '  Hello World  '
result = text.strip().lower().replace('world', 'python')
print(result)
```

실행 결과:
```
hello python
```

한 단계씩 풀어 쓰면:

```python
text = '  Hello World  '
step1 = text.strip()                       # '  Hello World  ' → 'Hello World'       (str 을 돌려줌)
step2 = step1.lower()                      # 'Hello World'     → 'hello world'       (str 을 돌려줌)
step3 = step2.replace('world', 'python')   # 'hello world'     → 'hello python'      (str 을 돌려줌)
print(step1)
print(step2)
print(step3)
```

실행 결과:
```
Hello World
hello world
hello python
```

💬 **설명 포인트 — 학생들에게 이렇게 설명하세요**
- 점 하나가 끝날 때마다 **그 자리가 반환값으로 바뀐다**고 생각하면 됩니다.
  `text.strip().lower()` → `'Hello World'.lower()` → `'hello world'`
- 그래서 체이닝을 읽을 때는 **각 단계의 반환 타입**을 알아야 합니다. 앞 단계가 문자열을 돌려주니까 다음에 문자열 메서드(`.lower()`)를 쓸 수 있는 것입니다.
- **반환값이 `None` 인 메서드 뒤에는 체이닝을 할 수 없습니다.** `lst.append(1).append(2)` → `None.append(2)` → `AttributeError`.

### 14-4. 심화 미리보기: `df.isna().sum().sum()`

판다스 코드를 미리 보면서 "왜 sum 이 두 번?" 을 풀어봅니다. (판다스 자체는 심화에서 자세히)

```python
import pandas as pd

df = pd.DataFrame({'Age': [22, None, 30], 'Cabin': [None, None, 'C85']})
print(df)
print('---- 1단계: df.isna() → 표(DataFrame). 각 칸이 비었으면 True')
print(df.isna())
print('---- 2단계: .sum() → 열마다 True 개수를 센 Series')
print(df.isna().sum())
print('---- 3단계: .sum() 한 번 더 → 그 숫자들의 합 = 전체 빈 칸 수 (정수 하나)')
print(df.isna().sum().sum())
```

실행 결과:
```
    Age Cabin
0  22.0  None
1   NaN  None
2  30.0   C85
---- 1단계: df.isna() → 표(DataFrame). 각 칸이 비었으면 True
     Age  Cabin
0  False   True
1   True   True
2  False  False
---- 2단계: .sum() → 열마다 True 개수를 센 Series
Age      1
Cabin    2
dtype: int64
---- 3단계: .sum() 한 번 더 → 그 숫자들의 합 = 전체 빈 칸 수 (정수 하나)
3
```

| 단계 | 코드 | 반환 타입 | 모양 |
|---|---|---|---|
| 0 | `df` | DataFrame | 3행 × 2열 표 |
| 1 | `df.isna()` | DataFrame | 3행 × 2열 (True/False) |
| 2 | `df.isna().sum()` | Series | 2개 (열별 개수) |
| 3 | `df.isna().sum().sum()` | 정수 | 숫자 1개 |

💬 **설명 포인트**: "`.sum()` 은 **한 차원을 줄인다**. 표(2차원) → 줄(1차원) → 숫자(0차원). 그래서 표 전체의 합을 구하려면 두 번 해야 한다." 이 감각이 생기면 심화 코드가 술술 읽힙니다.
